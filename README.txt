DREAMFLORAART WEBSITE — FIRST COMPLETE PROTOTYPE

Files:
- index.html       Customer-facing DreamFloraArt store
- admin.html       Mobile-friendly artwork dashboard
- styles.css       Full visual design
- app.js           Store/gallery/cart logic
- admin.js         Dashboard/product management logic

HOW TO TEST:
1. Open index.html in a browser.
2. Open admin.html to add/edit/delete artworks.
3. The dashboard stores demo data in the browser's localStorage.

IMPORTANT:
This is a functional front-end prototype, not yet the production backend.
For the public shop, the next backend phase should add:
- secure admin authentication
- shared cloud database
- permanent image storage
- customer accounts (optional)
- real orders
- secure checkout/payment
- shipping/tax handling
- live currency conversion/rates
- email/order notifications

The design is intentionally based on the user's supplied DreamFloraArt reference image:
storybook/fairytale, royal, floral, warm paper, framed artwork and rose accents.
